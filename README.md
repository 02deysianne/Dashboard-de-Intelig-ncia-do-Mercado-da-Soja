AgroData PR — Dashboard de Inteligência do Mercado da Soja

Dashboard interativo desenvolvido em **Python, Streamlit e Plotly** para monitoramento e análise do mercado da soja no Paraná. O projeto reúne indicadores econômicos e agropecuários, dados históricos de preços do DERAL e análises estatísticas para explorar tendências, correlações e possíveis fatores relacionados à variação do preço da soja.

# Funcionalidades

- Visualização interativa de indicadores de mercado.
- Análise exploratória e estatísticas descritivas.
- Análise de correlações e defasagens temporais (lags).
- Monitoramento de sinais de atenção.
- Modelagem preditiva com Ridge Regression.
- Comparação entre preços observados e previstos.
- Histórico de preços da soja no Paraná (DERAL).
- Filtros de período e gráficos interativos.

# Tecnologias

Python · Pandas · Streamlit · Plotly · Scikit-learn · Análise de Séries Temporais
